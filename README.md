# 🎨 React Native UI & Theme Showcase App

A modern, cross-platform mobile application built with **React Native (Expo)** and **TypeScript**, designed to explore, test, and showcase various trending UI/UX design aesthetics and philosophies (starting with **Glassmorphism** and **Dark Mode**) with real-time theme toggling.

---

## ✨ Features

- **Dynamic Theme Switcher:** Seamlessly switch between different UI design systems on the fly using state-driven style mapping.

- **Glassmorphism Design System:** Frosted glass cards (`expo-blur`), vibrant background gradients (`expo-linear-gradient`), translucent form inputs, and glowing interactive buttons.

- **Cross-Platform Ready:** Fully responsive layouts optimized for iOS, Android, and Web via Expo.

- **Modular Architecture:** Clean separation of concerns with components organized by design aesthetics in a dedicated `src/` folder.

---

## 🛠️ Tech Stack & Libraries

- **Framework:** [React Native](https://reactnative.dev/) via [Expo](https://expo.dev/) (SDK 57+)

- **Language:** TypeScript

- **Styling & Effects:** 

  * `expo-blur` (for frosted glass backdrop effects)
  * `expo-linear-gradient` (for vibrant aurora background gradients)
  * React Native StyleSheet API
